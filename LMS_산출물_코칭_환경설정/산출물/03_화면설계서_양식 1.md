# 화면 설계서 (1시간 미니판)

> 뭐예요? 화면마다 무엇을 입력하고, 버튼을 누르면 무슨 일이 생기는지 적은 문서예요.
> 💡 시작 질문: 수강 신청 버튼을 누르면 서버에 무엇을 보내야 할까요?

## 1. 화면 목록
화면 이동만 하는 버튼은 API 칸에 "없음(화면 이동)"이라고 적어요.

| 화면 ID   | 화면 이름 | 관련 FR  | 입력칸/버튼          | 필수·규칙                                                   | 누르면 → 호출 API ID |
| ------- | ----- | ------ | --------------- | ------------------------------------------------------- | --------------- |
| SCR-001 | 수강 신청 | FR-001 | 수강 신청 버튼        | 수강 신청 버튼을 누르면 해당 강의에 수강 신청이 된다.                         | 없음              |
| SCR-002 | 과정 변경 | FR-002 | 과정 변경 버튼        | 버튼을 누를시 이전 강의는 자동으로 수강신청 취소처리되며, 학생이 지정한 강의에 수강 신청을 한다. | 없음              |
| SCR-003 | 과제 제출 | FR-003 | 과제 본문, 과제 답 입력칸 | 과제 본문과 답은 필수다                                           | API-001         |

## 2. 메시지
| 칸      | 문장 (화면에 그대로 띄울 문장) |
| ------ | ------------------ |
| 성공 메시지 | 수강 신청이 완료되었습니다.    |
| 오류 메시지 | 정원 초과된 강의입니다.      |

## 3. 🖼 화면 스케치
위 3개 화면 중 입력칸·버튼이 있는 화면 1개를 네모로 그려요. 입력칸·버튼에는 1번 표와 같은 이름을 적어요.

## 스스로 점검
- [x] ★ 화면 3개 모두 관련 FR 번호가 있다
- [x] ★ 버튼마다 호출 API ID가 있다 (화면 이동은 "없음(화면 이동)")
- [x] 입력칸마다 필수 여부와 검사 규칙이 있다
- [x] 🖼 스케치 속 입력칸·버튼 이름이 1번 표와 같다
- [x] 메시지가 화면에 그대로 띄울 완성된 문장이다
