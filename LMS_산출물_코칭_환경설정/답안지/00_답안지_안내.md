## 실제 자료에서 찾은 문제 (답안에 반영)
- DDL: ENROLL·SUBMISSION에 UNIQUE 없음, NOT NULL 없음, 비밀번호 평문, ROLE_CD·SUBMISSION.STATUS_CD 공통코드 FK 없음, 취소·대기 코드 없음, 이력 컬럼 없음, FK 인덱스·시퀀스 없음
- ERD 문서와 실제 DDL의 테이블 이름이 다름 (TB_USER ↔ USERS, TB_FILE ↔ FILE_DATA 등)
- 화면: 과제 출제(LMS-008) 화면 없음, 로그인 화면 ID 없음, 로그아웃 위치 없음
- 요구사항: LMS-007이 한 줄에 두 기능(승인·취소)

## 쓰는 방법
- 수업 전에 담당자가 채점 기준을 맞춰 볼 때 써요.
- API URL은 예시예요. 실제 백엔드 소스와 다르면 소스 기준으로 고쳐요.
- 완료 보고서의 "일부" 표시와 시간 숫자는 **예시**예요.
