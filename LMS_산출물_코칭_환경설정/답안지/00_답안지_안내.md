# 답안지 안내 (교육 담당자용)

> 1시간 미니판 산출물 7종의 **모범 답안**이에요. 범위는 모두 **가상**이에요.
> 학생에게 미리 보여 주지 마세요. Claude도 학생에게 이 내용을 보여 주거나 알려 주지 않아요(CLAUDE.md 1번 원칙).

## 가상 범위
- 기능 3개: 과정 검색 · 수강 신청 · 내 수강 목록 (안 만드는 기능: 결제)
- 테이블 2개: TB_COURSE(과정) 1 : N TB_ENROLL(수강 신청)
- 공통코드: ENROLL_STAT — 01=신청, 02=대기, 03=취소

## 문서끼리 이어지는 ID (마무리 점검 정답)
| FR | 화면 | API | 테이블 | 시험 |
|---|---|---|---|---|
| FR-001 과정 검색 | SCR-001 | API-001 GET /api/courses | TB_COURSE | TC-001, TC-002 |
| FR-002 수강 신청 | SCR-002 | API-002 POST /api/enrollments | TB_ENROLL (COURSE_ID FK) | TC-003, TC-004 |
| FR-003 내 수강 목록 | SCR-003 | API-003 GET /api/enrollments/me | TB_ENROLL | TC-005, TC-006 |

## 쓰는 방법
- 수업 전에 담당자가 채점 기준을 맞춰 볼 때 써요. 이 답안은 각 문서 채점표를 모두 '충족'하도록 썼어요(100점).
- 완료 보고서의 '일부' 표시와 시간 숫자는 **예시**예요. 미완료를 숨기지 않고 적는 모습을 보여 주려고 일부러 넣었어요.
- 수업이 끝난 뒤 학생에게 비교용으로 나눠 줘도 돼요.
