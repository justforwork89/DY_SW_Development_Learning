# 요구사항 정의서 (1시간 미니판) — 답안

| ID | 사용자 | 요구 (한 줄에 하나) | 합격 기준 | 우선순위 | 화면 ID | API ID | 시험 ID |
|---|---|---|---|---|---|---|---|
| FR-001 | 수강생 | 수강생이 과정명으로 과정을 검색한다. | 검색어 "자바"를 넣으면 과정명에 "자바"가 들어간 과정만 과정명·정원·시작일과 함께 보인다. 검색어가 없으면 전체 과정이 보인다. | 상 | SCR-001 | API-001 | TC-001, TC-002 |
| FR-002 | 수강생 | 수강생이 과정을 수강 신청한다. | 신청하면 TB_ENROLL에 상태 01(신청)로 저장되고 "수강 신청이 완료되었어요."가 뜬다. 같은 과정을 다시 신청하면 저장되지 않는다. | 상 | SCR-002 | API-002 | TC-003, TC-004 |
| FR-003 | 수강생 | 수강생이 내 수강 목록을 본다. | 로그인한 본인이 신청한 과정만 신청일이 최근인 순서로 보인다. | 중 | SCR-003 | API-003 | TC-005, TC-006 |
| NFR-001 | 성능 | 과정 목록 조회는 3초 이내에 끝난다. | 동시 사용자 30명일 때 API-001 응답 시간이 3초 이내다. | 중 | - | - | - |
| NFR-002 | 개인정보 | 다른 수강생의 수강 내역은 볼 수 없다. | 로그인하지 않고 API-003을 부르면 401이 오고, 본인 것만 조회된다(STUDENT_ID는 로그인 정보에서 꺼냄). | 상 | - | - | - |
