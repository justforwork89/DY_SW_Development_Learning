## 주요 이동 흐름 (메뉴구조도 4번)
- 학습자: 로그인 → 홈 → 과정 목록 → 과정 상세 → 수강신청 → 나의 수강 현황 → 과제 목록 → 과제 제출
- 강사: 로그인 → 홈 → 과정 관리(등록) → 과제 목록 → 과제 채점
- 관리자: 로그인 → 관리 → 수강 승인 → 사용자 관리
