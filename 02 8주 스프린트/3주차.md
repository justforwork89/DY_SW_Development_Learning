### 스마트팩토리 / 제조 IT 시스템 - 업무 시스템 공통 핵심기능 정리

MES/QMS/ERP/WMS는 업무 시스템이라 화면 유형이 비슷하고, 대부분 **"조회 → 목록 → 편집 → 저장"** 패턴의 반복입니다.

**공통 핵심 기능 (거의 모든 화면)**

- **데이터 그리드**
  - 정렬, 필터, 페이징 또는 가상 스크롤
  - 컬럼 고정, 크기 조절, 순서 변경
  - 인라인 편집, 다중 선택, 합계/소계 행, 행 추가/삭제
  - 엑셀 다운로드, 엑셀 붙여넣기
  - 자주 쓰는 라이브러리: AG Grid, RealGrid, Handsontable, TanStack Table, Flutter는 PlutoGrid 등
- **조회 조건 영역**: 기간 선택, 콤보박스, 자동완성, 조회 조건 저장
- **코드 검색 팝업**: 품목, 거래처, 작업자, 설비 같은 마스터 데이터를 팝업이나 자동완성으로 선택
- **마스터-디테일 화면**: 위쪽은 헤더(수주, 작업지시), 아래쪽은 상세(품목 라인)
- **탭 기반 다중 화면(MDI)**: 여러 메뉴를 탭으로 열어 두고 작업
- **폼 입력과 검증**: 필수값, 형식 체크, 숫자/날짜/통화 포맷, 입력 마스크, 중복 체크
- **권한 제어**: 메뉴 트리, 역할별 화면/버튼(조회, 저장, 삭제) 권한
- **엑셀 업로드**: 대량 등록 시 검증 결과를 행별로 표시
- **인쇄와 리포트**: PDF 출력, 라벨 출력, 명세서, 성적서
- **파일 첨부, 공통코드, 다국어**

**시스템별로 특히 많이 쓰이는 기능**

| 시스템 | 대표 프론트엔드 기능 |
|---|---|
| MES | 실시간 설비/라인 현황판, 생산 실적 입력(터치 화면), 작업지시 간트차트, 알람 팝업, WebSocket/SSE 기반 갱신, OEE·생산량 차트 |
| QMS | 검사 성적서 입력, SPC 관리도(X-bar, R chart), 부적합/CAPA 워크플로우, 결재선 UI, 전자서명, 변경 이력(Audit Trail), 문서 버전 관리 |
| ERP | BOM 트리, 전표/주문 입력 화면, 복잡한 그리드(수식, 합계), 결재/승인, 기간 마감 처리, 대시보드 |
| WMS | 바코드/QR 스캔 입력, PDA/모바일 화면, 입출고 검수, 로케이션 맵(창고 레이아웃), 피킹 리스트, 라벨 프린트 |
