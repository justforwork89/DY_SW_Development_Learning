# 5주차

## 학습 내용


- 기능 추가 요청 내용 정리
1. 강사가 수업 참고자료 등록시 첨부파일 등록 기능 
2. 학생이 강사가 내준 과제 제출시 첨부파일 등록 기능 
3. 공통코드 목록 트리형태로 나타내도록 상위( 코드그룹 ) , 하위 ( 코드 그룹에 해당되는 코드 )


- 문제 발견 내용 정리
1. 교수가 강의 등록후 관리자 승인되지도 않았는데 미승인된 강의가 학생한테 보이는 문제 확인됨
2. 진행중은 강의 기간이 도래하면 자동으로 변경되는 상태인데 과정 개설시 선택 가능하게 되어 있음
3. 타강사의 과정상세로 들어오면 참고자료 등록할수 있는 문제 확인됨
4. 과정 상태 진행중, 모집중 곂치는 문제 확인되서 모집 시작, 종료일도 있어야됨
5. 과정관리에서 모집기간 확인 안됨
