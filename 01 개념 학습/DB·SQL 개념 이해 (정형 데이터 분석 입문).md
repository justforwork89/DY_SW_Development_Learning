# DB·SQL 개념 이해 (정형 데이터 분석 입문)

> [!warning] 💡
> **한 줄 정리**: SQL은 표에서 원하는 정보를 콕 집어 꺼내고 세는 도구이고, 사진·글·예측처럼 표로 안 되는 일은 다른 분석 방법이 맡아요. 실제로는 SQL로 데이터를 먼저 꺼내고, 그 데이터를 통계나 머신러닝으로 더 깊게 분석하는 식으로 같이 쓰는 경우가 많아요.

## 1. 정형 데이터가 뭘까?

정형 데이터는 칸이 딱딱 맞춰진 표 모양의 데이터예요. 학교 출석부나 성적표를 떠올리면 돼요.

| 이름 | 학년 | 좋아하는 과일 | 키(cm) |
| --- | --- | --- | --- |
| 민수 | 5 | 사과 | 140 |
| 지아 | 5 | 딸기 | 138 |
| 하준 | 6 | 사과 | 150 |

세로줄(이름, 학년…)은 항목이고, 가로줄 하나는 한 사람의 정보예요. 이렇게 줄과 칸이 정해져 있는 데이터가 정형 데이터예요.

## 2. SQL은 뭘까?

SQL은 이런 표에게 질문하는 말이에요. 도서관 사서 선생님께 "공룡 책 있어요?" 하고 물어보면 찾아주시죠? SQL은 컴퓨터 속 표에게 그렇게 물어보는 거예요.

## 3. 예시

**질문 1. 5학년 친구만 보여줘**

```sql
SELECT 이름 FROM 학생 WHERE 학년 = 5;
```

→ 민수, 지아

**질문 2. 사과를 좋아하는 친구는 몇 명이야?**

```sql
SELECT COUNT(*) FROM 학생 WHERE 좋아하는과일 = '사과';
```

→ 2명

**질문 3. 학년별 평균 키는?**

```sql
SELECT 학년, AVG(키) FROM 학생 GROUP BY 학년;
```

→ 5학년 139cm, 6학년 150cm

영어 문장처럼 읽히죠. "학생 표에서 학년이 5인 이름을 골라줘"라는 뜻이에요.

## 4. 어디에 쓰일까? (활용 예)

- **편의점·마트**: "어제 가장 많이 팔린 과자는?", "비 오는 날 우산이 몇 개 팔렸지?"
- **게임 회사**: "이번 주에 로그인한 사람은 몇 명?", "레벨 10에서 가장 많이 그만두네?"
- **병원**: 환자 진료 기록에서 "감기 환자가 몇 월에 가장 많을까?"
- **은행·쇼핑몰**: 거래 내역과 주문 내역을 정리하고 합계를 내요.
- **학교**: 성적 평균, 출석률 계산

SQL을 쓰면 수만, 수억 줄의 표에서도 몇 초 만에 답을 찾을 수 있어요.

## 5. SQL 말고 다른 데이터 분석도 있을까?

네, 많아요. 데이터의 모양이 표가 아닐 때나 표로는 알기 어려운 걸 알고 싶을 때 다른 방법을 써요.

### ① 비정형 데이터 분석

사진, 영상, 음성, 글처럼 표에 못 넣는 데이터를 다뤄요.

- 예: 후기 글에서 "맛있다"가 많은지 "별로"가 많은지 알아내기 (텍스트 분석)
- 예: 사진 속에서 고양이를 찾아내기 (이미지 분석)

### ② 통계 분석

"남자아이와 여자아이의 평균 키가 진짜 다를까, 우연일까?"처럼 숫자를 근거로 확인하는 방법이에요. 논문이나 연구에서 많이 써요. (Python, R, SPSS 등)

### ③ 머신러닝·인공지능

과거 데이터를 보고 미래를 예측해요. 예를 들면 "이 손님은 다음에 뭘 살까?", "내일 매출은 얼마일까?"를 맞히는 거예요.

### ④ 시각화(그래프 그리기)

숫자를 막대·원·선 그래프로 그려서 한눈에 보이게 해요. (Excel, Tableau, Power BI)

### ⑤ 반정형·그래프 데이터 분석

친구 관계처럼 "누가 누구와 연결됐는지"를 분석해요. SNS의 "알 수도 있는 친구"가 이런 방식이에요.
