# DB 모델링 학습노트 (5일 과정)

> [!info] 🎯
> **교육 목표**: 업무 현실을 충실하게 반영하면서 시스템 구축까지 고려한 데이터 모델을 만들 수 있는 능력을 기른다.<br>**교육 대상**: 개발자, 설계자, DBA

> [!note] 📚
> **공통 예제**: 모든 예제는 Project 1 **학습관리(LMS)**를 기준으로 해요. 학생이 과목을 수강신청하고, 강사가 과목을 가르치는 상황이에요. 일부 예제(BOM, 상태 전이)는 Project 2 **자산관리(AMS)**를 사용해요.

## 5일 과정 한눈에 보기

| 일차 | 주제 | 핵심 질문 |
| --- | --- | --- |
| 1일차 | 데이터 모델링 기초 · 개념 모델 | 무엇을 저장할까? |
| 2일차 | 논리 모델 · 정규화 · 반정규화 | 어떻게 중복 없이 나눌까? |
| 3일차 | 통합 · 이력 관리 · 모델링 패턴 | 어떻게 단순하고 오래 쓰게 만들까? |
| 4일차 | 고급 패턴 · 표준화 · 물리 모델 시작 | 실제 테이블로 어떻게 바꿀까? |
| 5일차 | 성능 · 무결성 · 인덱스 · 파티션 · 산출물 | 빠르고 정확하게 돌아가게 하려면? |

## 설계 흐름

```javascript
업무 파악 → 개념 모델 → 논리 모델(정규화) → 물리 모델(테이블·인덱스·파티션) → DDL 생성 → 산출물(ERD·테이블 정의서)
  1일차        1일차        2~3일차               4~5일차                       5일차
```
