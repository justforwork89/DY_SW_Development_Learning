# LMS 단위테스트 결과서

## 주요 내용

테스트 케이스, 입력/예상/실제 결과, P/F

## 1. 개요

- 대상: LMS 백엔드(Spring Boot 서비스·API) + 프론트엔드(Flutter ViewModel)
- 기준 문서: [[LMS 요구사항 정의서]], [[LMS 메뉴구조도]], [[LMS 과정 관리 화면]]
- 작성일: 2026-11-02 (v0.1)
- 판정 방식: **코드 검토 기준 1차 판정.** 실제 실행 결과는 로컬 실행 후 `실행 결과` 칸에 기록한다.
  - P: 코드상 예상 결과대로 동작함
  - F: 코드상 예상 결과와 다르게 동작함 (결함)
- 공통 응답 형식: `{ success, message, data }` — 아래 "실제 결과"는 HTTP 상태와 message 기준

## 5. 비고

- 백엔드 자동 테스트는 현재 `LmsApplicationTest.contextLoads` 1건뿐이며, DB 연결이 없으면 실패한다. 위 케이스를 서비스 계층 JUnit + Mockito 테스트로 옮기면 DB 없이 반복 실행할 수 있다.
- 미구현 기능(페이징, 첨부파일 업로드, 수강 현황 조회, 대시보드 API 등)은 단위테스트 대상에서 제외했다.
