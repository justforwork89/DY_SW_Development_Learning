# LMS 과정 관리 화면

## 1. 화면 개요

- 화면 ID: LMS-C003 / 화면명: 과정 관리
- 목적: 강사·관리자가 교육과정을 조회·등록·수정하고 상태를 변경한다.
- 접근 권한: 강사(T), 관리자(A) — 강사는 본인이 운영하는 과정만 수정할 수 있다.
- 구현: Flutter (목록 화면 + 등록/수정 화면), Spring Boot REST API 연동
- 관련 요구사항: LMS-003, LMS-004, LMS-005

## 2. 화면 구성 (와이어프레임)

```txt
┌──────────────────────────────────────┐
│ ← 과정 관리                  [+ 등록] │
├──────────────────────────────────────┤
│ [검색어 입력       ] [상태 ▼] [조회]  │
├──────────────────────────────────────┤
│ 과정명    강사     기간       상태    │
│ ───────────────────────────────────- │
│ Spring 입문   홍길동   10/12~11/06  모집중 │
│ Flutter 기초  김강사   11/09~12/04  준비중 │
│ ...                                   │
│              < 1 2 3 >                │
└──────────────────────────────────────┘
```

## 3. 조회 조건 / 목록

| 구분 | 항목 | 형식 | 비고 |
| --- | --- | --- | --- |
| 조회 조건 | 과정명 | 텍스트 | 부분 일치 검색 |
| 조회 조건 | 상태 | 드롭다운 | 전체 / 준비중 / 모집중 / 진행중 / 종료 (공통코드) |
| 목록 컬럼 | 과정명 | 텍스트 | 탭하면 상세·수정 화면으로 이동 |
| 목록 컬럼 | 강사 | 텍스트 | 사용자 테이블 조인 |
| 목록 컬럼 | 교육기간 | 날짜 범위 | 시작일 ~ 종료일 |
| 목록 컬럼 | 정원 / 신청 | 숫자 | 예: 20 / 12 |
| 목록 컬럼 | 상태 | 라벨 | 상태별 색상 구분 |

## 4. 등록/수정 입력 항목

| 항목     | 필수  | 형식                  | 검증 규칙                        |
| ------ | --- | ------------------- | ---------------------------- |
| 과정명    | Y   | 텍스트 (최대 100자)       | 공백만 입력 불가                    |
| 과정 설명  | N   | 여러 줄 텍스트 (최대 2000자) | -                            |
| 담당 강사  | Y   | 선택                  | 강사 권한 사용자만 선택 가능             |
| 교육 시작일 | Y   | 날짜                  | -                            |
| 교육 종료일 | Y   | 날짜                  | 시작일보다 빠를 수 없음                |
| 정원     | Y   | 숫자                  | 1 이상 정수, 신청 인원보다 작게 수정 불가    |
| 상태     | Y   | 드롭다운                | 준비중 → 모집중 → 진행중 → 종료 순서로만 변경 |

## 5. 버튼 / 이벤트

| 버튼 | 동작 | 호출 API |
| --- | --- | --- |
| 조회 | 조건에 맞는 과정 목록 조회 (페이징 10건) | GET /api/courses |
| 등록 | 등록 화면으로 이동 | - |
| 저장 | 입력값 검증 후 신규 등록 또는 수정 | POST /api/courses, PUT /api/courses/\{id\} |
| 상태 변경 | 허용된 다음 상태로 변경 | PATCH /api/courses/\{id\}/status |
| 삭제 | 신청자가 없는 과정만 삭제 (확인 팝업) | DELETE /api/courses/\{id\} |

## 6. 상태 전이 규칙

- 준비중 → 모집중 → 진행중 → 종료 (역방향 불가)
- 모집중으로 변경할 때 정원과 교육기간이 입력되어 있어야 한다.
- 종료된 과정은 수정할 수 없고 조회만 가능하다.

## 7. Flutter 구현 메모

- 목록: `ListView.builder` + 무한 스크롤(또는 페이지 버튼), 상태는 Riverpod/Provider로 관리
- 입력 폼: `Form` + `TextFormField` validator로 위 검증 규칙 적용
- 날짜 선택: `showDatePicker`, API 통신: `dio` 또는 `http` 패키지 (JSON 직렬화)
- 오류 응답은 SnackBar로 안내하고, 서버 검증 메시지를 그대로 표시한다.
