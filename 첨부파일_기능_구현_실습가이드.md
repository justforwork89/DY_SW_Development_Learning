# 📎 LMS 첨부파일 기능 직접 만들기 (실습 가이드)

> **대상**: 군복무대체 SW 실습생
> **기술**: Spring Boot 4 · MyBatis · Oracle · Flyway (백엔드) / Flutter Web · MVVM (프론트)
> **만들 것**: ① 강사가 올리는 **강의 참고자료** ② 학생이 내는 **과제 제출 파일**
> **예상 시간**: 백엔드 3~4시간 · 프론트 3~4시간

---

## 0. 이 문서 사용법

- 단계마다 **[목표] → [왜?] → [할 일] → [코드] → [✅ 확인] → [⚠️ 막히는 곳]** 순서로 되어 있어요.
- **Part B(강사 참고자료)는 코드를 보며 따라 만들고**, **Part C(학생 과제 파일)는 먼저 혼자 만들어 본 뒤** 접힌 정답(`▶ 정답 코드 보기`)과 비교하세요. B와 C는 90% 같은 모양이라, B를 이해했다면 C는 혼자 할 수 있어요.
- 한 단계를 끝낼 때마다 **서버(또는 Flutter)를 다시 켜서 확인**하고 넘어가세요. 여러 단계를 한꺼번에 고치면 어디서 틀렸는지 찾기 어려워요.
- 코드 블록 첫 줄의 `// 파일:` 주석이 **파일 위치**예요. (`…/lms/` = `backend/src/main/java/com/dy/lms/`)

## 1. 큰 그림 — 파일 하나가 올라가는 길

### 1-1. 택배로 비유하면

| 실제 | 비유 |
|---|---|
| 파일 | 택배 상자 |
| 서버 폴더 `D:/lms-files` | **창고** (상자를 실제로 쌓아 두는 곳) |
| DB 표 `TB_COURSE_FILE` | **장부** (어떤 상자가 창고 몇 번 칸에 있는지 적은 공책) |
| UUID 저장 이름 | 창고 칸 번호 (이름이 겹치지 않게 랜덤 번호) |
| 권한 검사 | 경비원 (아무나 상자를 넣거나 꺼내지 못하게) |

> **핵심 한 줄**: 파일은 **창고(디스크)** 에, 파일 정보는 **장부(DB)** 에 따로 둔다. 둘이 항상 짝이 맞아야 한다.

### 1-2. 올리기(업로드) 흐름

```
[Flutter 화면]                         [Spring 서버]                              [저장]
 파일 선택 버튼
   │ file_picker로 파일 고르기
   ▼
 ViewModel: 개수·용량 미리 검사
   │ multipart/form-data (key = files)
   ▼
 ApiClient.upload ──────────────▶ SecurityConfig (역할 1차 검사)
                                     ▼
                                  Controller  (@RequestPart("files"))
                                     ▼
                                  Service: 권한 2차 → 개수·용량 → 확장자
                                     ▼
                                  FileStorageService.store ───────────▶ D:/lms-files/…/UUID.pdf (창고)
                                     ▼
                                  Mapper.insert ──────────────────────▶ TB_COURSE_FILE (장부)
 ◀───────────── 저장된 파일 정보(JSON) ─┘
 목록에 추가해서 보여주기
```

### 1-3. 내려받기(다운로드) 흐름

```
 다운로드 버튼 → GET /api/files/{id}/download
   → Service: 볼 수 있는 사람인가? (경비원)
   → 장부에서 창고 위치 찾기 → 디스크에서 파일 읽기
   → 원래 이름(한글 OK)으로 내려보내기 → 브라우저가 저장
```

### 1-4. 두 기능의 규칙 비교

| | 강사 **참고자료** | 학생 **과제 제출 파일** |
|---|---|---|
| 어디에 붙나 | 강의(TB_COURSE) 1개 → 파일 n개 | 제출(TB_SUBMISSION) 1건 → 파일 n개 |
| 올리기·지우기 | 관리자, **그 강의의 담당 강사** | **제출한 학생 본인**, 마감 전·채점 전 |
| 보기·내려받기 | 관리자, 담당 강사, **수강 승인된 학생** | 학생 본인, 그 강의 담당 강사, 관리자 |
| 제한 | 한 번에 **20개 · 500MB** | 제출 1건에 합쳐서 **5개 · 50MB** |
| 저장 폴더 | `course/{강의ID}/연/월/` | `submission/{제출ID}/연/월/` |
| 언제 올라가나 | 고르자마자 바로 | **제출 버튼**을 누를 때 (본문 저장 → 파일 업로드) |

## 2. 무엇부터 이해해야 하나 (공부 순서)

1. **파일은 디스크, 정보는 DB** — 왜 DB에 파일을 통째로 넣지 않을까? (DB가 무거워지고 느려져요)
2. **multipart/form-data** — 글자(JSON)가 아니라 "상자 여러 개"를 한 번에 보내는 방식. 서버는 `@RequestPart("files")`로 받아요. 이름 `files`가 양쪽에서 **똑같아야** 해요.
3. **UUID 저장 이름** — 학생 둘이 `보고서.pdf`를 올려도 덮어쓰지 않게, 창고에는 `3f2a…e1.pdf`로 저장하고 원래 이름은 장부에 적어요.
4. **경비원 두 명** — `SecurityConfig`(역할만 봄: 학생이냐 강사냐) + `Service`(진짜 주인인지 봄: 내 강의냐, 내 제출이냐).
5. **창고와 장부 짝 맞추기** — DB 저장이 실패하면 이미 창고에 넣은 파일도 지워야 해요(트랜잭션 + 예약 삭제).
6. **화면 쪽 MVVM** — Repository(서버와 대화) → ViewModel(상태·규칙) → View(그리기).

```yaml
  tomcat:

app:

    max-files-per-upload: 20
    submission:
```

| 설정 | 뜻 |
|---|---|
| `max-file-size` / `max-request-size` | 서버 문 크기. 이보다 크면 Controller까지 오지도 못하고 413 |
| `server.tomcat.max-part-count` | 한 요청에 들어올 수 있는 조각 수 (파일 20개 + 여유) |
| `allowed-extensions` | 올릴 수 있는 확장자 목록 (`.exe` 같은 위험 파일 막기) |

⚠️ **yml은 띄어쓰기(들여쓰기)가 틀리면 서버가 안 켜져요.** 탭(Tab) 말고 스페이스로 맞추세요.

# Part A. 백엔드 공통 — 창고 관리인 `FileStorageService`

### [목표] 디스크에 파일을 **넣고 · 찾고 · 지우는** 일만 하는 클래스

### [왜?]
참고자료도, 과제 파일도 "디스크에 저장"하는 방법은 똑같아요. 그래서 한 곳에 모아 두고 두 기능이 같이 써요. 이 클래스는 **DB를 모릅니다**. 오직 창고만 관리해요.

### [코드]

```java
// 파일: …/lms/service/FileStorageService.java
package com.dy.lms.service;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.time.LocalDate;
import java.time.format.DateTimeFormatter;
import java.util.List;
import java.util.Locale;
import java.util.Set;
import java.util.UUID;
import java.util.stream.Collectors;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;
import org.springframework.util.StringUtils;
import org.springframework.web.multipart.MultipartFile;

import com.dy.lms.common.BusinessException;

import lombok.extern.slf4j.Slf4j;

@Slf4j
@Service
//디스크에 파일을 넣고, 찾고, 지웁니다. (DB는 CourseFileService·SubmissionFileService 담당)
public class FileStorageService {

    private static final DateTimeFormatter YEAR_MONTH = DateTimeFormatter.ofPattern("yyyy/MM");

    private final Path root;                     // D:/lms-files
    private final Set<String> allowedExtensions; // pdf, pptx, ...

    // yml 값을 읽어서 채운다
    public FileStorageService(@Value("${app.file.upload-dir}") String uploadDir,
                              @Value("${app.file.allowed-extensions}") List<String> allowed) {
        this.root = Paths.get(uploadDir).toAbsolutePath().normalize();
        this.allowedExtensions = allowed.stream()
                .map(s -> s.trim().toLowerCase(Locale.ROOT))
                .collect(Collectors.toSet());
    }

    /** 저장 결과 영수증 (이 값을 DB에 적는다) */
    public record StoredFile(String originName, String saveName, String relativeDir,
                             long size, String contentType) {}

    /** ① 확장자 검사 */
    public void validate(MultipartFile file) {
        String ext = StringUtils.getFilenameExtension(originName(file));
        if (ext == null || !allowedExtensions.contains(ext.toLowerCase(Locale.ROOT))) {
            throw new BusinessException("올릴 수 없는 파일 형식입니다: " + originName(file));
        }
    }

    /** ② 저장(참고자료): D:/lms-files/course/{강의ID}/{연}/{월}/{UUID}.{확장자} */
    public StoredFile store(MultipartFile file, Long courseId) {
        return store(file, "course/" + courseId);
    }
    
    
    /** ②-1 저장(폴더 지정): D:/lms-files/{folder}/{연}/{월}/{UUID}.{확장자}
     *  과제 제출은 folder = "submission/{제출ID}" */
    public StoredFile store(MultipartFile file, String folder) {
        String originName = originName(file);
        String ext = StringUtils.getFilenameExtension(originName).toLowerCase(Locale.ROOT);
        String saveName = UUID.randomUUID() + "." + ext;
        String relativeDir = folder + "/" + LocalDate.now().format(YEAR_MONTH);

        Path dir = safeResolve(relativeDir);
        try {
            Files.createDirectories(dir);           // 폴더가 없으면 만든다
            file.transferTo(dir.resolve(saveName)); // 파일을 옮겨 놓는다
        } catch (IOException e) {
            throw new BusinessException("파일을 저장하지 못했습니다: " + originName);
        }
        return new StoredFile(originName, saveName, relativeDir, file.getSize(), file.getContentType());
    }

    /** ③ 찾기: DB의 폴더 + 저장 이름 → 실제 위치 */
    public Path load(String relativeDir, String saveName) {
        return safeResolve(relativeDir + "/" + saveName);
    }

    /** ④ 지우기 (실패해도 멈추지 않고 로그만 남김) */
    public void delete(String relativeDir, String saveName) {
        try {
            Files.deleteIfExists(load(relativeDir, saveName));
        } catch (Exception e) {
            log.warn("파일 삭제 실패: {}/{}", relativeDir, saveName, e);
        }
    }

    private static final int MAX_NAME_LENGTH = 80;   // 한글 80자 = 240바이트 < DB 255바이트

    /** C:\a\보고서.pdf → 보고서.pdf, 제어 문자 제거, 너무 길면 확장자는 살리고 자름 */
    private String originName(MultipartFile file) {
        String name = StringUtils.getFilename(StringUtils.cleanPath(String.valueOf(file.getOriginalFilename())));
        if (name == null || name.isBlank()) {
            return "file";
        }
        name = name.replaceAll("\\p{Cntrl}", "_");
        if (name.length() > MAX_NAME_LENGTH) {
            String ext = StringUtils.getFilenameExtension(name);
            String base = StringUtils.stripFilenameExtension(name);
            int keep = MAX_NAME_LENGTH - (ext == null ? 0 : ext.length() + 1);
            name = base.substring(0, Math.max(1, keep)) + (ext == null ? "" : "." + ext);
        }
        return name;
    }
    /** 합친 경로가 D:/lms-files 안쪽인지 확인 (../../ 장난 막기) */
    private Path safeResolve(String relative) {
        Path resolved = root.resolve(relative).normalize();
        if (!resolved.startsWith(root)) {
            throw new BusinessException("잘못된 파일 경로입니다.");
        }
        return resolved;
    }
}
```

### 핵심 줄 설명

| 메서드 | 하는 일 | 왜 필요? |
|---|---|---|
| `validate` | 확장자 검사 | `.exe`, `.jsp` 같은 위험한 파일 막기 |
| `store(file, folder)` | `folder/연/월/UUID.확장자`로 저장 | 이름 겹침 방지 + 폴더 하나에 파일이 너무 많이 쌓이지 않게 |
| `originName` | `C:\a\보고서.pdf` → `보고서.pdf`, 80자 자르기 | 브라우저마다 경로를 붙여 보내기도 함 / DB 칸 크기(255byte) 지키기 |
| `safeResolve` | 합친 경로가 창고 안쪽인지 확인 | `../../Windows` 같은 **경로 탈출 공격** 막기 |

### ✅ 확인
아직 부르는 곳이 없으니 **서버가 에러 없이 켜지면** 통과.

# Part B. 강사 참고자료 (따라 만들기)

## B-1. DB 표 (장부)

### [할 일] `db/sql`에 새 파일 → 서버를 켜면 Flyway가 자동 실행

```sql
-- 파일: backend/src/main/resources/db/sql/V10__create_tb_course_file.sql
CREATE TABLE TB_COURSE_FILE (
    FILE_ID       NUMBER GENERATED ALWAYS AS IDENTITY,
    COURSE_ID     NUMBER         NOT NULL,
    ORIGIN_NAME   VARCHAR2(255)  NOT NULL,
    SAVE_NAME     VARCHAR2(100)  NOT NULL,
    FILE_PATH     VARCHAR2(300)  NOT NULL,
    FILE_SIZE     NUMBER(12)     NOT NULL,
    CONTENT_TYPE  VARCHAR2(100),
    UPLOADER_ID   VARCHAR2(30)   NOT NULL,
    REG_DT        DATE           DEFAULT SYSDATE NOT NULL,
    CONSTRAINT PK_TB_COURSE_FILE PRIMARY KEY (FILE_ID),
    CONSTRAINT FK_COURSE_FILE_COURSE FOREIGN KEY (COURSE_ID) REFERENCES TB_COURSE (COURSE_ID),
    CONSTRAINT FK_COURSE_FILE_UPLOADER FOREIGN KEY (UPLOADER_ID) REFERENCES TB_USER (USER_ID)
);

CREATE INDEX IX_COURSE_FILE_COURSE ON TB_COURSE_FILE (COURSE_ID);
```

| 칸 | 뜻 |
|---|---|
| `ORIGIN_NAME` | 사용자가 올린 원래 이름 (`보고서.pdf`) |
| `SAVE_NAME` | 창고에 저장한 이름 (`3f2a….pdf`) |
| `FILE_PATH` | 창고 안 폴더 (`course/3/2026/11`) — **D:/ 같은 절대경로는 저장 안 함**(서버를 옮겨도 되게) |

### ✅ 확인
서버 로그에 `Migrating schema … to version "10"` → SQL Developer에서 `SELECT * FROM TB_COURSE_FILE;` 실행 시 빈 표가 보이면 통과.

## B-2. Domain · DTO · Mapper

### [왜?]
- **Domain(`CourseFile`)**: DB 한 줄을 담는 서버 내부용 그릇
- **DTO(`CourseFileResponse`)**: 화면에 보낼 것만 고른 그릇 → `saveName`, `filePath`는 **밖으로 안 보냄**(창고 위치는 비밀)
- **Mapper**: DB에 시킬 일 목록(.java) + 실제 SQL(.xml)

```java
// 파일: …/lms/domain/CourseFile.java
package com.dy.lms.domain;

import java.time.LocalDateTime;

import lombok.Getter;
import lombok.NoArgsConstructor;
import lombok.Setter;

@Getter
@Setter
@NoArgsConstructor
// TB_COURSE_FILE 한 행을 담는 내부용 그릇입니다.
public class CourseFile {
    private Long fileId;
    private Long courseId;
    private String originName;
    private String saveName;
    private String filePath;
    private Long fileSize;
    private String contentType;
    private String uploaderId;
    private LocalDateTime regDt;
}
```

```java
// 파일: …/lms/dto/CourseFileResponse.java
package com.dy.lms.dto;

import java.time.LocalDateTime;

import com.dy.lms.domain.CourseFile;

// 화면으로 내려보내는 첨부파일 정보입니다.
public record CourseFileResponse(
        Long id,
        Long courseId,
        String name,
        Long size,
        String contentType,
        String uploaderId,
        LocalDateTime regDt) {

    public static CourseFileResponse from(CourseFile f) {
        return new CourseFileResponse(
                f.getFileId(), f.getCourseId(), f.getOriginName(),
                f.getFileSize(), f.getContentType(), f.getUploaderId(), f.getRegDt());
    }
}
```

```xml
            useGeneratedKeys="true" keyProperty="fileId" keyColumn="FILE_ID">

                                    FILE_SIZE, CONTENT_TYPE, UPLOADER_ID)
        VALUES (#{courseId}, #{originName}, #{saveName}, #{filePath},
                #{fileSize}, #{contentType}, #{uploaderId})
    </insert>

    <select id="findByCourseId" resultType="CourseFile">
        SELECT <include refid="columns"/>
          FROM TB_COURSE_FILE
         WHERE COURSE_ID = #{courseId}
         ORDER BY FILE_ID
    </select>

    <select id="findById" resultType="CourseFile">
        SELECT <include refid="columns"/>
          FROM TB_COURSE_FILE
         WHERE FILE_ID = #{fileId}
    </select>

    <delete id="delete">
        DELETE FROM TB_COURSE_FILE WHERE FILE_ID = #{fileId}
    </delete>

    <delete id="deleteByCourseId">
        DELETE FROM TB_COURSE_FILE WHERE COURSE_ID = #{courseId}
    </delete>
</mapper>
```

## B-3. Service — 업무 규칙 (가장 중요 ⭐)

### [왜?]
"누가 올릴 수 있나, 몇 개까지, 실패하면 어떻게 치우나"를 모두 여기서 정해요. Controller는 받기만, Service가 판단해요.

```java
// 파일: …/lms/service/CourseFileService.java
package com.dy.lms.service;

import java.nio.file.Files;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.List;
import com.dy.lms.domain.Enrollment;
import com.dy.lms.mapper.EnrollmentMapper;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import org.springframework.transaction.support.TransactionSynchronization;
import org.springframework.transaction.support.TransactionSynchronizationManager;
import org.springframework.web.multipart.MultipartFile;

import com.dy.lms.common.BusinessException;
import com.dy.lms.domain.Course;
import com.dy.lms.domain.CourseFile;
import com.dy.lms.dto.CourseFileResponse;
import com.dy.lms.mapper.CourseFileMapper;
import com.dy.lms.mapper.CourseMapper;
import com.dy.lms.service.FileStorageService.StoredFile;

import lombok.RequiredArgsConstructor;

@Service
@RequiredArgsConstructor
// 첨부파일 업무 규칙(검사, 권한, 디스크·DB 맞추기)을 처리합니다.
public class CourseFileService {

    private static final long MAX_TOTAL_BYTES = 500L * 1024 * 1024;   // 500MB

    private final CourseFileMapper courseFileMapper;
    private final CourseMapper courseMapper;
    private final FileStorageService storage;
    private final EnrollmentMapper enrollmentMapper;
    
    @Value("${app.file.max-files-per-upload:20}")
    private int maxFilesPerUpload;

    /** 업로드: 검사 → 디스크 저장 → DB 기록 */
    @Transactional
    public List<CourseFileResponse> upload(Long courseId, List<MultipartFile> files,
                                           String userId, boolean admin) {
        checkOwner(getCourse(courseId), userId, admin);

        List<MultipartFile> real = files == null ? List.of()
                : files.stream().filter(f -> !f.isEmpty()).toList();
        if (real.isEmpty()) {
            throw new BusinessException(HttpStatus.BAD_REQUEST, "올릴 파일을 선택하세요.");
        }
        if (real.size() > maxFilesPerUpload) {
            throw new BusinessException(HttpStatus.BAD_REQUEST,
                    "한 번에 " + maxFilesPerUpload + "개까지 올릴 수 있습니다.");
        }
        long total = real.stream().mapToLong(MultipartFile::getSize).sum();
        if (total > MAX_TOTAL_BYTES) {
            throw new BusinessException(HttpStatus.CONTENT_TOO_LARGE,
                    "한 번에 올릴 수 있는 용량은 500MB까지입니다.");
        }
        real.forEach(storage::validate);           // 1) 저장 전에 전부 검사

        List<StoredFile> written = new ArrayList<>();
        deleteWrittenIfRollback(written);          // 2) 실패하면 디스크 파일도 지우도록 예약

        List<CourseFileResponse> result = new ArrayList<>();
        for (MultipartFile f : real) {
            StoredFile s = storage.store(f, courseId);   // 3) 디스크에 저장
            written.add(s);

            CourseFile row = new CourseFile();           // 4) DB에 기록
            row.setCourseId(courseId);
            row.setOriginName(s.originName());
            row.setSaveName(s.saveName());
            row.setFilePath(s.relativeDir());
            row.setFileSize(s.size());
            row.setContentType(s.contentType());
            row.setUploaderId(userId);
            courseFileMapper.insert(row);                // 생성된 fileId가 row에 채워짐

            result.add(CourseFileResponse.from(courseFileMapper.findById(row.getFileId())));
        }
        return result;
    }

    /** 목록: 볼 수 있는 사람만 */
    public List<CourseFileResponse> list(Long courseId, String userId, boolean admin) {
        checkReadable(getCourse(courseId), userId, admin);
        return courseFileMapper.findByCourseId(courseId).stream()
                .map(CourseFileResponse::from)
                .toList();
    }

    /** 다운로드용 1건: 볼 수 있는 사람인지까지 확인 */
    public CourseFile getFileForDownload(Long fileId, String userId, boolean admin) {
        CourseFile file = getFile(fileId);
        checkReadable(getCourse(file.getCourseId()), userId, admin);
        return file;
    }

    private static final String ENROLL_APPROVED = "20";   // 공통코드 ENROLL_STATUS '승인'

    /** 관리자, 담당 강사, 수강 승인된 학생만 볼 수 있다 */
    private void checkReadable(Course c, String userId, boolean admin) {
        if (admin || c.getInstructorId().equals(userId)) {
            return;
        }
        Enrollment e = enrollmentMapper.findByStudentAndCourse(userId, c.getCourseId());
        if (e == null || !ENROLL_APPROVED.equals(e.getStatusCd())) {
            throw new BusinessException(HttpStatus.FORBIDDEN, "수강 승인된 강의의 자료만 볼 수 있습니다.");
        }
    }
    
    /** 1건 */
    public CourseFile getFile(Long fileId) {
        CourseFile file = courseFileMapper.findById(fileId);
        if (file == null) {
            throw new BusinessException(HttpStatus.NOT_FOUND, "파일 정보를 찾을 수 없습니다.");
        }
        return file;
    }

    /** 다운로드용: 실제 파일이 디스크에 있는지까지 확인 */
    public Path resolvePath(CourseFile file) {
        Path path = storage.load(file.getFilePath(), file.getSaveName());
        if (!Files.exists(path)) {
            throw new BusinessException(HttpStatus.NOT_FOUND, "서버에 파일이 없습니다.");
        }
        return path;
    }

    /** 삭제: DB 먼저, 성공하면 실제 파일 */
    @Transactional
    public void delete(Long fileId, String userId, boolean admin) {
        CourseFile file = getFile(fileId);
        checkOwner(getCourse(file.getCourseId()), userId, admin);
        courseFileMapper.delete(fileId);
        deleteFilesAfterCommit(List.of(file));
    }

    /** 강의 삭제 전에 CourseService가 부른다 */
    @Transactional
    public void deleteAllByCourse(Long courseId) {
        List<CourseFile> rows = courseFileMapper.findByCourseId(courseId);
        courseFileMapper.deleteByCourseId(courseId);
        deleteFilesAfterCommit(rows);
    }

    private Course getCourse(Long courseId) {
        Course c = courseMapper.findById(courseId);
        if (c == null) {
            throw new BusinessException(HttpStatus.NOT_FOUND, "강의를 찾을 수 없습니다.");
        }
        return c;
    }

    /** 관리자가 아니면 본인 강의만 (CourseService.checkOwner와 같은 규칙) */
    private void checkOwner(Course c, String userId, boolean admin) {
        if (!admin && !c.getInstructorId().equals(userId)) {
            throw new BusinessException(HttpStatus.FORBIDDEN, "본인 강의의 자료만 올리거나 삭제할 수 있습니다.");
        }
    }

    /** 예약: 일이 실패로 끝나면 저장해 둔 파일을 지운다 */
    private void deleteWrittenIfRollback(List<StoredFile> written) {
        TransactionSynchronizationManager.registerSynchronization(new TransactionSynchronization() {
            @Override
            public void afterCompletion(int status) {
                if (status != STATUS_COMMITTED) {
                    written.forEach(s -> storage.delete(s.relativeDir(), s.saveName()));
                }
            }
        });
    }

    /** 예약: 일이 성공으로 끝나면 실제 파일을 지운다 */
    private void deleteFilesAfterCommit(List<CourseFile> rows) {
        TransactionSynchronizationManager.registerSynchronization(new TransactionSynchronization() {
            @Override
            public void afterCommit() {
                rows.forEach(r -> storage.delete(r.getFilePath(), r.getSaveName()));
            }
        });
    }
}
```

### 핵심 포인트

| 부분 | 설명 |
|---|---|
| `checkOwner` | 올리기·지우기: 관리자 또는 **그 강의 담당 강사**만 |
| `checkReadable` | 보기·내려받기: 관리자, 담당 강사, **수강 승인(ENROLL '20')된 학생**만 |
| `real.forEach(storage::validate)` | **저장하기 전에 전부 검사** → 3번째 파일이 .exe면 1·2번째도 안 올라감 |
| `deleteWrittenIfRollback` | DB 저장이 실패하면(롤백) **이미 창고에 넣은 파일을 지움** → 장부 없는 유령 파일 방지 |
| `deleteFilesAfterCommit` | 삭제는 **DB 먼저**, 성공(커밋)한 뒤에 디스크 파일 삭제 → 반대 순서면 DB는 남고 파일만 사라질 수 있음 |

### 강의 삭제와 연결
강의를 지우면 그 강의 파일도 같이 지워야 해요. `CourseService.delete()`에 한 줄 추가:

```java

courseFileService.deleteAllByCourse(id);
```

## B-4. Controller · Security · 예외 처리

```java
// 파일: …/lms/controller/CourseFileController.java
package com.dy.lms.controller;

import java.nio.charset.StandardCharsets;
import java.nio.file.Path;
import java.util.List;

import org.springframework.core.io.FileSystemResource;
import org.springframework.core.io.Resource;
import org.springframework.http.ContentDisposition;
import org.springframework.http.HttpHeaders;
import org.springframework.http.MediaType;
import org.springframework.http.ResponseEntity;
import org.springframework.security.core.Authentication;
import org.springframework.web.bind.annotation.DeleteMapping;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestPart;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.multipart.MultipartFile;

import com.dy.lms.common.ApiResponse;
import com.dy.lms.domain.CourseFile;
import com.dy.lms.dto.CourseFileResponse;
import com.dy.lms.service.CourseFileService;

import lombok.RequiredArgsConstructor;

@RestController
@RequestMapping("/api")
@RequiredArgsConstructor
// 강의 참고자료(첨부파일) 입구입니다.
public class CourseFileController {

    private final CourseFileService courseFileService;

    // 업로드 (form-data, key = files)
    @PostMapping(value = "/courses/{courseId}/files", consumes = MediaType.MULTIPART_FORM_DATA_VALUE)
    public ApiResponse<List<CourseFileResponse>> upload(@PathVariable("courseId") Long courseId,
            @RequestPart("files") List<MultipartFile> files, Authentication auth) {
        return ApiResponse.ok(courseFileService.upload(courseId, files, auth.getName(), isAdmin(auth)));
    }

    // 목록
    @GetMapping("/courses/{courseId}/files")
    public ApiResponse<List<CourseFileResponse>> list(@PathVariable("courseId") Long courseId,
            Authentication auth) {
        return ApiResponse.ok(courseFileService.list(courseId, auth.getName(), isAdmin(auth)));
    }

    // 다운로드 (ApiResponse가 아니라 파일 내용 그대로)
    @GetMapping("/files/{fileId}/download")
    public ResponseEntity<Resource> download(@PathVariable("fileId") Long fileId, Authentication auth) {
        CourseFile file = courseFileService.getFileForDownload(fileId, auth.getName(), isAdmin(auth));
        Path path = courseFileService.resolvePath(file);

        // UUID가 아니라 원래 이름으로, 한글도 안 깨지게(UTF-8)
        ContentDisposition disposition = ContentDisposition.attachment()
                .filename(file.getOriginName(), StandardCharsets.UTF_8)
                .build();

        return ResponseEntity.ok()
                .header(HttpHeaders.CONTENT_DISPOSITION, disposition.toString())
                .contentType(MediaType.APPLICATION_OCTET_STREAM)   // 브라우저가 열지 않고 저장만
                .contentLength(file.getFileSize())
                .body(new FileSystemResource(path));                // 조금씩 읽어 보내서 메모리 안전
    }

    // 삭제
    @DeleteMapping("/files/{fileId}")
    public ApiResponse<Void> delete(@PathVariable("fileId") Long fileId, Authentication auth) {
        courseFileService.delete(fileId, auth.getName(), isAdmin(auth));
        return ApiResponse.ok();
    }

    private boolean isAdmin(Authentication auth) {
        return auth.getAuthorities().stream()
                .anyMatch(a -> a.getAuthority().equals("ROLE_ADMIN"));
    }
}
```

| 주소 | 하는 일 |
|---|---|
| `POST /api/courses/{courseId}/files` | 올리기 (form-data, key=`files`) |
| `GET /api/courses/{courseId}/files` | 목록 |
| `GET /api/files/{fileId}/download` | 내려받기 (JSON이 아니라 **파일 그대로**) |
| `DELETE /api/files/{fileId}` | 지우기 |

**다운로드에서 꼭 알아둘 것**
- `ContentDisposition.attachment().filename(이름, UTF_8)` → 한글 이름이 안 깨짐
- `APPLICATION_OCTET_STREAM` → 브라우저가 파일을 **열지 않고 저장만** (HTML 파일을 열어 스크립트가 실행되는 것 방지)
- `FileSystemResource` → 큰 파일도 메모리에 한꺼번에 올리지 않고 조금씩 보냄

**SecurityConfig (1차 경비원)** — `.anyRequest()` 위에 추가:

```java
// 파일: …/lms/config/SecurityConfig.java
.requestMatchers(HttpMethod.POST, "/api/courses/*/files").hasAnyRole("INSTRUCTOR", "ADMIN")
.requestMatchers(HttpMethod.DELETE, "/api/files/**").hasAnyRole("INSTRUCTOR", "ADMIN")
```

**GlobalExceptionHandler** — 서버 문(500MB)보다 큰 요청이 오면 Controller까지 못 오고 여기로 와요:

```java
// 파일: …/lms/common/GlobalExceptionHandler.java  (추가)
@ExceptionHandler(MaxUploadSizeExceededException.class)
public ResponseEntity<ApiResponse<Void>> handleMaxUpload(MaxUploadSizeExceededException e) {
    return ResponseEntity.status(HttpStatus.CONTENT_TOO_LARGE)
            .body(ApiResponse.fail("한 번에 올릴 수 있는 용량은 500MB까지입니다."));
}

@ExceptionHandler(MultipartException.class)
public ResponseEntity<ApiResponse<Void>> handleMultipart(MultipartException e) {
    return ResponseEntity.badRequest()
            .body(ApiResponse.fail("파일이 너무 많거나 업로드 요청이 올바르지 않습니다."));
}
```

⚠️ 이 두 개는 `@ExceptionHandler(Exception.class)`(모든 예외)보다 **구체적**이라 먼저 잡혀요. 없으면 "서버 오류가 발생했습니다"(500)로 나와요.

# Part C. 학생 과제 제출 파일 (혼자 만들어 보기 💪)

> Part B와 **같은 모양**이에요. 아래 "다른 점"만 생각하면서 먼저 혼자 만들고, 막히면 정답을 펼쳐 보세요.

### C-0. Part B와 다른 점 (이것만 바꾸면 돼요)

| | Part B (참고자료) | Part C (과제 파일) |
|---|---|---|
| 붙는 곳 | `COURSE_ID` | `SUBMISSION_ID` |
| 올린 사람 칸 | `UPLOADER_ID` 있음 | **없음** (제출한 학생 = 주인) |
| 올리기 권한 | 담당 강사 | **제출한 학생 본인 + 채점 전 + 마감 전** |
| 개수·용량 | 이번 요청만 검사 (20개·500MB) | **이미 올린 것 + 이번 것** 합쳐서 (5개·50MB) |
| 저장 폴더 | `"course/" + courseId` | `"submission/" + submissionId` |
| 주소 | `/api/files/…` | `/api/submission-files/…` (헷갈리지 않게) |

### C-4. Service

💡 **혼자 해볼 때 힌트**
- 권한 검사를 두 개로 나누세요: `checkEditable`(올리기·지우기) / `checkReadable`(보기)
- `checkEditable`: ① `submission.getStudentId().equals(userId)` ② `getScore() == null` ③ 지금 < 마감일
- `checkReadable`: 관리자 or 본인 → 통과 / 아니면 과제 → 강의 → `instructorId`가 나인지
- 개수 검사: `findBySubmissionId(...).size() + 이번 개수 > maxFiles`
- `@Value("${app.file.submission.max-files:5}")` — `:5`는 설정이 없을 때 기본값

<details><summary>▶ 정답 코드 보기 — SubmissionFileService.java</summary>

```java
// 파일: …/lms/service/SubmissionFileService.java
package com.dy.lms.service;

import java.nio.file.Files;
import java.nio.file.Path;
import java.time.LocalDateTime;
import java.util.ArrayList;
import java.util.List;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import org.springframework.transaction.support.TransactionSynchronization;
import org.springframework.transaction.support.TransactionSynchronizationManager;
import org.springframework.web.multipart.MultipartFile;

import com.dy.lms.common.BusinessException;
import com.dy.lms.domain.Assignment;
import com.dy.lms.domain.Submission;
import com.dy.lms.domain.SubmissionFile;
import com.dy.lms.dto.SubmissionFileResponse;
import com.dy.lms.mapper.SubmissionFileMapper;
import com.dy.lms.mapper.SubmissionMapper;
import com.dy.lms.service.FileStorageService.StoredFile;

import lombok.RequiredArgsConstructor;

@Service
@RequiredArgsConstructor
// 과제 제출 첨부파일 업무 규칙(권한, 개수·용량 제한, 디스크·DB 맞추기)을 처리합니다.
public class SubmissionFileService {

    private final SubmissionFileMapper submissionFileMapper;
    private final SubmissionMapper submissionMapper;
    private final AssignmentService assignmentService;
    private final CourseService courseService;
    private final FileStorageService storage;

    @Value("${app.file.submission.max-files:5}")
    private int maxFiles;            // 제출 1건에 최대 개수

    @Value("${app.file.submission.max-total-mb:50}")
    private long maxTotalMb;         // 제출 1건 전체 용량(MB)

    /** 업로드: 권한 → 개수·용량(이미 올린 것 포함) → 확장자 → 디스크 저장 → DB 기록 */
    @Transactional
    public List<SubmissionFileResponse> upload(Long submissionId, List<MultipartFile> files, String userId) {
        Submission submission = getSubmission(submissionId);
        checkEditable(submission, userId);

        List<MultipartFile> real = files == null ? List.of()
                : files.stream().filter(f -> !f.isEmpty()).toList();
        if (real.isEmpty()) {
            throw new BusinessException(HttpStatus.BAD_REQUEST, "올릴 파일을 선택하세요.");
        }

        List<SubmissionFile> already = submissionFileMapper.findBySubmissionId(submissionId);
        if (already.size() + real.size() > maxFiles) {
            throw new BusinessException(HttpStatus.BAD_REQUEST,
                    "과제 1건에 파일은 " + maxFiles + "개까지 붙일 수 있습니다. (지금 " + already.size() + "개)");
        }
        long total = already.stream().mapToLong(SubmissionFile::getFileSize).sum()
                + real.stream().mapToLong(MultipartFile::getSize).sum();
        if (total > maxTotalMb * 1024 * 1024) {
            throw new BusinessException(HttpStatus.CONTENT_TOO_LARGE,
                    "과제 1건의 파일은 합쳐서 " + maxTotalMb + "MB까지입니다.");
        }
        real.forEach(storage::validate);           // 1) 저장 전에 전부 검사

        List<StoredFile> written = new ArrayList<>();
        deleteWrittenIfRollback(written);          // 2) 실패하면 디스크 파일도 지우도록 예약

        List<SubmissionFileResponse> result = new ArrayList<>();
        for (MultipartFile f : real) {
            StoredFile s = storage.store(f, "submission/" + submissionId);   // 3) 디스크에 저장
            written.add(s);

            SubmissionFile row = new SubmissionFile();                        // 4) DB에 기록
            row.setSubmissionId(submissionId);
            row.setOriginName(s.originName());
            row.setSaveName(s.saveName());
            row.setFilePath(s.relativeDir());
            row.setFileSize(s.size());
            row.setContentType(s.contentType());
            submissionFileMapper.insert(row);

            result.add(SubmissionFileResponse.from(submissionFileMapper.findById(row.getFileId())));
        }
        return result;
    }

    /** 목록: 볼 수 있는 사람만 */
    public List<SubmissionFileResponse> list(Long submissionId, String userId, boolean admin) {
        checkReadable(getSubmission(submissionId), userId, admin);
        return submissionFileMapper.findBySubmissionId(submissionId).stream()
                .map(SubmissionFileResponse::from)
                .toList();
    }

    /** 다운로드용 1건: 볼 수 있는 사람인지까지 확인 */
    public SubmissionFile getFileForDownload(Long fileId, String userId, boolean admin) {
        SubmissionFile file = getFile(fileId);
        checkReadable(getSubmission(file.getSubmissionId()), userId, admin);
        return file;
    }

    /** 다운로드용: 실제 파일이 디스크에 있는지까지 확인 */
    public Path resolvePath(SubmissionFile file) {
        Path path = storage.load(file.getFilePath(), file.getSaveName());
        if (!Files.exists(path)) {
            throw new BusinessException(HttpStatus.NOT_FOUND, "서버에 파일이 없습니다.");
        }
        return path;
    }

    /** 삭제: 올린 학생 본인만, DB 먼저 지우고 성공하면 실제 파일 */
    @Transactional
    public void delete(Long fileId, String userId) {
        SubmissionFile file = getFile(fileId);
        checkEditable(getSubmission(file.getSubmissionId()), userId);
        submissionFileMapper.delete(fileId);
        deleteFilesAfterCommit(List.of(file));
    }

    /** 올리기·지우기: 제출한 학생 본인 + 채점 전 + 마감 전 */
    private void checkEditable(Submission s, String userId) {
        if (!s.getStudentId().equals(userId)) {
            throw new BusinessException(HttpStatus.FORBIDDEN, "본인 과제에만 파일을 올리거나 지울 수 있습니다.");
        }
        if (s.getScore() != null) {
            throw new BusinessException(HttpStatus.BAD_REQUEST, "채점이 끝난 과제는 파일을 바꿀 수 없습니다.");
        }
        Assignment a = assignmentService.findById(s.getAssignmentId());
        if (LocalDateTime.now().isAfter(a.getDueDate())) {
            throw new BusinessException(HttpStatus.BAD_REQUEST, "과제 마감일이 지났습니다.");
        }
    }

    /** 보기·내려받기: 제출한 학생 본인, 그 강의 담당 강사, 관리자 */
    private void checkReadable(Submission s, String userId, boolean admin) {
        if (admin || s.getStudentId().equals(userId)) {
            return;
        }
        Assignment a = assignmentService.findById(s.getAssignmentId());
        String instructorId = courseService.findById(a.getCourseId()).instructorId();
        if (!instructorId.equals(userId)) {
            throw new BusinessException(HttpStatus.FORBIDDEN, "이 과제의 제출 파일을 볼 수 없습니다.");
        }
    }

    private Submission getSubmission(Long submissionId) {
        Submission s = submissionMapper.findById(submissionId);
        if (s == null) {
            throw new BusinessException(HttpStatus.NOT_FOUND, "제출 내역을 찾을 수 없습니다.");
        }
        return s;
    }

    private SubmissionFile getFile(Long fileId) {
        SubmissionFile file = submissionFileMapper.findById(fileId);
        if (file == null) {
            throw new BusinessException(HttpStatus.NOT_FOUND, "파일 정보를 찾을 수 없습니다.");
        }
        return file;
    }

    /** 예약: 일이 실패로 끝나면 저장해 둔 파일을 지운다 */
    private void deleteWrittenIfRollback(List<StoredFile> written) {
        TransactionSynchronizationManager.registerSynchronization(new TransactionSynchronization() {
            @Override
            public void afterCompletion(int status) {
                if (status != STATUS_COMMITTED) {
                    written.forEach(s -> storage.delete(s.relativeDir(), s.saveName()));
                }
            }
        });
    }

    /** 예약: 일이 성공으로 끝나면 실제 파일을 지운다 */
    private void deleteFilesAfterCommit(List<SubmissionFile> rows) {
        TransactionSynchronizationManager.registerSynchronization(new TransactionSynchronization() {
            @Override
            public void afterCommit() {
                rows.forEach(r -> storage.delete(r.getFilePath(), r.getSaveName()));
            }
        });
    }
}
```

```java
package com.dy.lms.controller;

import java.nio.charset.StandardCharsets;
import java.nio.file.Path;
import java.util.List;

import org.springframework.core.io.FileSystemResource;
import org.springframework.core.io.Resource;
import org.springframework.http.ContentDisposition;
import org.springframework.http.HttpHeaders;
import org.springframework.http.MediaType;
import org.springframework.http.ResponseEntity;
import org.springframework.security.core.Authentication;
import org.springframework.web.bind.annotation.DeleteMapping;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestPart;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.multipart.MultipartFile;

import com.dy.lms.common.ApiResponse;
import com.dy.lms.domain.SubmissionFile;
import com.dy.lms.dto.SubmissionFileResponse;
import com.dy.lms.service.SubmissionFileService;

import lombok.RequiredArgsConstructor;

@RestController
@RequestMapping("/api")
@RequiredArgsConstructor
// 과제 제출 첨부파일 입구입니다.
public class SubmissionFileController {

    private final SubmissionFileService submissionFileService;

    // 업로드 (form-data, key = files) - 제출한 학생 본인만
    @PostMapping(value = "/submissions/{submissionId}/files", consumes = MediaType.MULTIPART_FORM_DATA_VALUE)
    public ApiResponse<List<SubmissionFileResponse>> upload(@PathVariable("submissionId") Long submissionId,
            @RequestPart("files") List<MultipartFile> files, Authentication auth) {
        return ApiResponse.ok(submissionFileService.upload(submissionId, files, auth.getName()));
    }

    // 목록 - 학생 본인, 담당 강사, 관리자
    @GetMapping("/submissions/{submissionId}/files")
    public ApiResponse<List<SubmissionFileResponse>> list(@PathVariable("submissionId") Long submissionId,
            Authentication auth) {
        return ApiResponse.ok(submissionFileService.list(submissionId, auth.getName(), isAdmin(auth)));
    }

    // 다운로드 (ApiResponse가 아니라 파일 내용 그대로)
    @GetMapping("/submission-files/{fileId}/download")
    public ResponseEntity<Resource> download(@PathVariable("fileId") Long fileId, Authentication auth) {
        SubmissionFile file = submissionFileService.getFileForDownload(fileId, auth.getName(), isAdmin(auth));
        Path path = submissionFileService.resolvePath(file);

        ContentDisposition disposition = ContentDisposition.attachment()
                .filename(file.getOriginName(), StandardCharsets.UTF_8)
                .build();

        return ResponseEntity.ok()
                .header(HttpHeaders.CONTENT_DISPOSITION, disposition.toString())
                .contentType(MediaType.APPLICATION_OCTET_STREAM)
                .contentLength(file.getFileSize())
                .body(new FileSystemResource(path));
    }

    // 삭제 - 제출한 학생 본인만
    @DeleteMapping("/submission-files/{fileId}")
    public ApiResponse<Void> delete(@PathVariable("fileId") Long fileId, Authentication auth) {
        submissionFileService.delete(fileId, auth.getName());
        return ApiResponse.ok();
    }

    private boolean isAdmin(Authentication auth) {
        return auth.getAuthorities().stream()
                .anyMatch(a -> a.getAuthority().equals("ROLE_ADMIN"));
    }
}
```

```bash
curl -s -H "Authorization: Bearer $STOKEN" localhost:8080/api/submissions
```

→ 응답의 `"id":숫자` 중 **마감 전 · `"score":null`** 인 것을 고르세요.

```bash
SID=21
```
```bash
curl -s -H "Authorization: Bearer $STOKEN" -F "files=@a.txt" -F "files=@b.txt" localhost:8080/api/submissions/$SID/files
```

| 시험 | 기대 결과 |
|---|---|
| 2개 올린 뒤 4개 더 (합쳐서 6개) | `과제 1건에 파일은 5개까지 붙일 수 있습니다. (지금 2개)` |
| 마감 지난 제출에 올리기 | `과제 마감일이 지났습니다.` |
| 채점 끝난 제출에 올리기 | `채점이 끝난 과제는 파일을 바꿀 수 없습니다.` |
| 다른 학생 토큰으로 올리기 | `본인 과제에만 파일을 올리거나 지울 수 있습니다.` |

## D-2. ApiClient에 upload / download 추가

```dart
// 파일: frontend/lib/api/api_client.dart  (전체)
import 'dart:async';
import 'dart:convert';
import 'dart:typed_data';

import 'package:flutter/foundation.dart';
import 'package:http/http.dart' as http;

import '../repositories/business_exception.dart';

/// 서버 응답(ApiResponse) 해석 결과.
class ApiResult {
  const ApiResult(this.status, this.success, this.message, this.data);

  final int status;
  final bool success;
  final String? message;
  final dynamic data;
}

/// Spring Boot 서버 호출 공통 클라이언트. 로그인 후 받은 토큰을 보관해 요청마다 붙인다.
class ApiClient {
  ApiClient({String? baseUrl}) : baseUrl = baseUrl ?? _defaultBaseUrl();

  final String baseUrl;
  String? token;

  static String _defaultBaseUrl() {
    // 안드로이드 에뮬레이터에서 PC의 localhost는 10.0.2.2
    if (!kIsWeb && defaultTargetPlatform == TargetPlatform.android) {
      return 'http://10.0.2.2:8080';
    }
    return 'http://localhost:8080';
  }

  /// 상태 코드와 본문을 그대로 돌려준다 (로그인처럼 401을 직접 처리할 때 사용).
  Future<ApiResult> raw(String method, String path, {Object? body}) async {
    final uri = Uri.parse('$baseUrl$path');
    final headers = <String, String>{
      'Content-Type': 'application/json; charset=UTF-8',
      if (token != null) 'Authorization': 'Bearer $token',
    };
    final encoded = body == null ? null : jsonEncode(body);

    http.Response res;
    try {
      switch (method) {
        case 'GET':
          res = await http.get(uri, headers: headers);
        case 'POST':
          res = await http.post(uri, headers: headers, body: encoded);
        case 'PUT':
          res = await http.put(uri, headers: headers, body: encoded);
        case 'PATCH':
          res = await http.patch(uri, headers: headers, body: encoded);
        case 'DELETE':
          res = await http.delete(uri, headers: headers);
        default:
          throw ArgumentError('지원하지 않는 메서드: $method');
      }
    } on ArgumentError {
      rethrow;
    } catch (_) {
      throw const BusinessException('서버에 연결할 수 없습니다.');
    }

    return _toResult(res);
  }

  /// 성공이면 data를, 실패면 서버 메시지로 [BusinessException]을 던진다.
  Future<dynamic> call(String method, String path, {Object? body}) async {
    final r = await raw(method, path, body: body);
    if (!r.success) {
      throw BusinessException(r.message ?? '요청을 처리하지 못했습니다.');
    }
    return r.data;
  }

  Map<String, String> get _authHeader => {
    if (token != null) 'Authorization': 'Bearer $token',
  };

  /// 서버 응답을 ApiResult로 해석 (raw, upload, download가 같이 씀)
  ApiResult _toResult(http.Response res) {
    Map<String, dynamic> json = {};
    try {
      final decoded = jsonDecode(utf8.decode(res.bodyBytes));
      if (decoded is Map<String, dynamic>) json = decoded;
    } catch (_) {}
    return ApiResult(
      res.statusCode,
      json['success'] == true,
      json['message'] as String?,
      json['data'],
    );
  }

  /// 파일 업로드 (multipart). onProgress(보낸 byte, 전체 byte)
  Future<dynamic> upload(
    String path,
    List<http.MultipartFile> files, {
    void Function(int sent, int total)? onProgress,
  }) async {
    final req = _ProgressMultipartRequest(
      'POST',
      Uri.parse('$baseUrl$path'),
      onProgress,
    );
    req.headers.addAll(_authHeader); // Content-Type은 자동으로 붙음
    req.files.addAll(files);

    http.Response res;
    try {
      res = await http.Response.fromStream(await req.send());
    } catch (_) {
      throw const BusinessException('서버에 연결할 수 없습니다.');
    }
    final r = _toResult(res);
    if (!r.success) {
      throw BusinessException(
        r.message ??
            (res.statusCode == 413
                ? '한 번에 500MB까지 올릴 수 있습니다.'
                : '파일을 올리지 못했습니다.'),
      );
    }
    return r.data;
  }

  /// 파일 다운로드. 성공하면 파일 내용(bytes)
  Future<Uint8List> download(String path) async {
    http.Response res;
    try {
      res = await http.get(Uri.parse('$baseUrl$path'), headers: _authHeader);
    } catch (_) {
      throw const BusinessException('서버에 연결할 수 없습니다.');
    }
    if (res.statusCode != 200) {
      throw BusinessException(_toResult(res).message ?? '파일을 받지 못했습니다.');
    }
    return res.bodyBytes;
  }
}

/// 업로드할 때 몇 byte 보냈는지 세는 요청 (진행 막대용)
class _ProgressMultipartRequest extends http.MultipartRequest {
  _ProgressMultipartRequest(super.method, super.url, this.onProgress);

  final void Function(int sent, int total)? onProgress;

  @override
  http.ByteStream finalize() {
    final stream = super.finalize();
    final total = contentLength;
    var sent = 0;
    return http.ByteStream(
      stream.transform(
        StreamTransformer<List<int>, List<int>>.fromHandlers(
          handleData: (chunk, sink) {
            sent += chunk.length;
            onProgress?.call(sent, total);
            sink.add(chunk);
          },
        ),
      ),
    );
  }
}
```

| 부분 | 설명 |
|---|---|
| `upload` | `MultipartRequest`로 파일 여러 개를 한 번에. **Content-Type을 직접 넣지 마세요**(경계값 boundary가 자동으로 붙어야 함) |
| `_ProgressMultipartRequest` | 보낸 byte를 세서 **진행률 막대**에 씀 |
| `download` | 파일 내용(bytes)을 받음. 실패면 서버 JSON 메시지를 꺼내 에러로 |

```dart
import 'package:http/http.dart' as http;

import '../models/course_file.dart';
import '../repositories/course_file_repository.dart';
import 'api_client.dart';
import 'save_file.dart';

class ApiCourseFileRepository implements CourseFileRepository {
  ApiCourseFileRepository(this._api);

  final ApiClient _api;

  @override
  Future<List<CourseFile>> fetchFiles(int courseId) async {
    final data =
        await _api.call('GET', '/api/courses/$courseId/files') as List<dynamic>;
    return [
      for (final e in data) CourseFile.fromJson(e as Map<String, dynamic>),
    ];
  }

  @override
  Future<List<CourseFile>> upload(
    int courseId,
    List<UploadFile> files, {
    void Function(double progress)? onProgress,
  }) async {
    final parts = [
      // 'files' = 서버 @RequestPart("files")와 같은 이름 (curl의 -F "files=@...")
      for (final f in files)
        http.MultipartFile('files', f.stream, f.size, filename: f.name),
    ];
    final data =
        await _api.upload(
              '/api/courses/$courseId/files',
              parts,
              onProgress: (sent, total) {
                if (total > 0) onProgress?.call(sent / total);
              },
            )
            as List<dynamic>;
    return [
      for (final e in data) CourseFile.fromJson(e as Map<String, dynamic>),
    ];
  }

  @override
  Future<String> download(CourseFile file) async {
    final bytes = await _api.download('/api/files/${file.id}/download');
    return saveBytes(file.name, bytes);
  }

  @override
  Future<void> delete(int fileId) async {
    await _api.call('DELETE', '/api/files/$fileId');
  }
}
```

```dart
import 'package:flutter/foundation.dart';

import '../models/course_file.dart';

/// 과정 참고자료 ViewModel. 목록, 업로드 진행률, 권한을 관리한다.
class CourseFileViewModel extends ChangeNotifier {
  CourseFileViewModel(this._repo, this.courseId, this._user, this._instructorId);

  final CourseFileRepository _repo;
  final int courseId;
  final AppUser _user;
  final String? _instructorId; // 이 강의를 맡은 강사 아이디

  List<CourseFile> _files = const [];
  bool _loading = false;
  double? _progress; // null이면 올리는 중이 아님
  String? _errorMessage;

  List<CourseFile> get files => _files;
  bool get loading => _loading;
  double? get progress => _progress;
  bool get busy => _progress != null;
  String? get errorMessage => _errorMessage;
  int get totalBytes => _files.fold(0, (sum, f) => sum + f.size);

  /// 올리기·삭제는 관리자 또는 "이 강의 담당 강사"만 (최종 판단은 서버가 한 번 더 함)
  bool get canManage =>
      _user.role == UserRole.admin ||
      (_user.role == UserRole.instructor && _user.id == _instructorId);

  Future<void> load() async {
    _loading = true;
    _errorMessage = null;
    notifyListeners();
    try {
      _files = await _repo.fetchFiles(courseId);
    } on BusinessException catch (e) {
      _errorMessage = e.message; // 예: 수강 승인된 강의의 자료만 볼 수 있습니다.
    } catch (_) {
      _errorMessage = '참고자료를 불러오지 못했습니다.';
    }
    _loading = false;
    notifyListeners();
  }

  /// 파일을 고르고 올린다. 보여줄 메시지를 돌려주고, 취소하면 null.
  Future<String?> pickAndUpload() async {
    // file_picker 13: 기본이 여러 개 선택, 취소하면 빈 목록
    final picked = await FilePicker.pickFiles(
      type: FileType.custom,
      allowedExtensions: allowedFileExtensions,
    );
    if (picked.isEmpty) return null;
    if (picked.length > maxFilesPerUpload) {
      return '한 번에 $maxFilesPerUpload개까지 올릴 수 있어요.';
    }

    final uploads = <UploadFile>[];
    var total = 0;
    for (final f in picked) {
      final size = await f.length(); // 13부터 크기를 알 수 없으면 null
      if (size == null) return '"${f.name}" 파일 크기를 알 수 없어요.';
      total += size;
      uploads.add(
        UploadFile(name: f.name, size: size, stream: f.readAsByteStream()),
      );
    }
    if (total > maxUploadBytes) {
      return '한 번에 500MB까지 올릴 수 있어요. (선택한 용량: ${formatBytes(total)})';
    }

    _progress = 0;
    notifyListeners();
    try {
      final added = await _repo.upload(
        courseId,
        uploads,
        onProgress: (p) {
          _progress = p;
          notifyListeners();
        },
      );
      _files = [..._files, ...added];
      return '${added.length}개 파일을 올렸습니다.';
    } on BusinessException catch (e) {
      return e.message;
    } catch (_) {
      return '파일을 올리지 못했습니다.';
    } finally {
      _progress = null;
      notifyListeners();
    }
  }

  Future<String> download(CourseFile file) async {
    try {
      final where = await _repo.download(file);
      return '저장했습니다: $where';
    } on BusinessException catch (e) {
      return e.message;
    } catch (_) {
      return '파일을 받지 못했습니다.';
    }
  }

  Future<String> delete(CourseFile file) async {
    try {
      await _repo.delete(file.id);
      _files = _files.where((f) => f.id != file.id).toList();
      notifyListeners();
      return '"${file.name}"을(를) 삭제했습니다.';
    } on BusinessException catch (e) {
      return e.message;
    } catch (_) {
      return '삭제하지 못했습니다.';
    }
  }
}
```

# Part F. Flutter 학생 과제 제출 화면 (혼자 만들어 보기 💪)

### F-0. Part E와 다른 점 — "바로 올리기" vs "모아 두었다가 제출할 때"

과제 파일은 **제출 번호(SID)가 있어야** 올릴 수 있어요. 그런데 처음 제출하는 학생은 아직 제출 번호가 없죠.

그래서:
1. 파일을 고르면 **올릴 목록(pending)** 에만 담아 둔다 (파란 ⬆ 표시 "제출하면 올라가요")
2. **[제출]** 을 누르면 → ① 본문 저장(제출 번호 받음) → ② 그 번호로 pending 파일 업로드 → ③ 화면 닫기

```
[파일 선택] → pending 목록에 쌓기 (아직 서버에 없음)
[제출]      → POST /api/submissions        → 제출 번호 21 받음
            → POST /api/submissions/21/files (pending 전부)
            → 성공하면 화면 닫기
```

```dart
            as List<dynamic>;
    return [
      for (final e in data) SubmissionFile.fromJson(e as Map<String, dynamic>),
    ];
  }

  @override
  Future<List<SubmissionFile>> upload(
    int submissionId,
    List<UploadFile> files, {
    void Function(double progress)? onProgress,
  }) async {
    final parts = [
      // 'files' = 서버 @RequestPart("files")와 같은 이름
      for (final f in files)
        http.MultipartFile('files', f.stream, f.size, filename: f.name),
    ];
    final data =
        await _api.upload(
              '/api/submissions/$submissionId/files',
              parts,
              onProgress: (sent, total) {
                if (total > 0) onProgress?.call(sent / total);
              },
            )
            as List<dynamic>;
    return [
      for (final e in data) SubmissionFile.fromJson(e as Map<String, dynamic>),
    ];
  }

  @override
  Future<String> download(SubmissionFile file) async {
    final bytes = await _api.download('/api/submission-files/${file.id}/download');
    return saveBytes(file.name, bytes);
  }

  @override
  Future<void> delete(int fileId) async {
    await _api.call('DELETE', '/api/submission-files/$fileId');
  }
}
```

### F-2. ViewModel (pending이 핵심 ⭐)

💡 **혼자 해볼 때 힌트**
- `PendingFile(name, size, open)` — `open`은 **나중에 업로드할 때** 파일을 읽는 함수 (`f.readAsByteStream`을 괄호 없이 넘김)
- `pick()`: 이미 올린 개수·용량 + pending + 새로 고른 것 합쳐서 5개·50MB 검사
- `uploadPending(int id)`: 제출 번호를 받아서 pending 전부 업로드 → 성공하면 `files`로 옮기고 pending 비우기
- `editable`: 학생 본인 + 마감 전 + 채점 전일 때만 `true` → 강사 화면에서는 `false`

<details><summary>▶ 정답 코드 보기 — submission_file_viewmodel.dart</summary>

```dart
// 파일: frontend/lib/viewmodels/submission_file_viewmodel.dart
import 'package:file_picker/file_picker.dart';
import 'package:flutter/foundation.dart';

import '../models/course_file.dart';
import '../models/submission_file.dart';
import '../repositories/business_exception.dart';
import '../repositories/submission_file_repository.dart';

/// 제출 버튼을 누르기 전까지 기다리는 파일 하나 (아직 서버에 없음)
class PendingFile {
  const PendingFile(this.name, this.size, this.open);
  final String name;
  final int size;
  final Stream<List<int>> Function() open; // 올릴 때 파일 내용을 읽는 방법
}

/// 과제 제출 첨부파일 ViewModel.
/// files = 이미 서버에 올라간 파일, pending = 제출을 누르면 올라갈 파일
class SubmissionFileViewModel extends ChangeNotifier {
  SubmissionFileViewModel(this._repo, {this.submissionId, this.editable = false});

  final SubmissionFileRepository _repo;
  int? submissionId;   // 아직 한 번도 제출 안 했으면 null
  final bool editable; // 학생 본인 + 마감 전 + 채점 전일 때만 true

  List<SubmissionFile> _files = const [];
  List<PendingFile> _pending = const [];
  bool _loading = false;
  double? _progress; // null이면 올리는 중이 아님
  String? _errorMessage;

  List<SubmissionFile> get files => _files;
  List<PendingFile> get pending => _pending;
  bool get loading => _loading;
  double? get progress => _progress;
  bool get busy => _progress != null;
  String? get errorMessage => _errorMessage;
  bool get hasPending => _pending.isNotEmpty;
  int get totalCount => _files.length + _pending.length;
  int get totalBytes =>
      _files.fold(0, (sum, f) => sum + f.size) +
      _pending.fold(0, (sum, p) => sum + p.size);

  /// 이미 올린 파일 목록 불러오기 (제출 전이면 할 일 없음)
  Future<void> load() async {
    final id = submissionId;
    if (id == null) return;
    _loading = true;
    _errorMessage = null;
    notifyListeners();
    try {
      _files = await _repo.fetchFiles(id);
    } on BusinessException catch (e) {
      _errorMessage = e.message;
    } catch (_) {
      _errorMessage = '첨부 파일을 불러오지 못했습니다.';
    }
    _loading = false;
    notifyListeners();
  }

  /// 파일 고르기: 바로 올리지 않고 '올릴 목록'에 담는다. 문제가 있으면 메시지, 괜찮으면 null.
  Future<String?> pick() async {
    final picked = await FilePicker.pickFiles(
      type: FileType.custom,
      allowedExtensions: allowedFileExtensions,
    );
    if (picked.isEmpty) return null; // 취소
    if (totalCount + picked.length > maxSubmissionFiles) {
      return '파일은 최대 $maxSubmissionFiles개까지 붙일 수 있어요. (지금 $totalCount개)';
    }
    final added = <PendingFile>[];
    var bytes = totalBytes;
    for (final f in picked) {
      final size = await f.length();
      if (size == null) return '"${f.name}" 파일 크기를 알 수 없어요.';
      bytes += size;
      added.add(PendingFile(f.name, size, f.readAsByteStream));
    }
    if (bytes > maxSubmissionBytes) {
      return '합쳐서 50MB까지 붙일 수 있어요. (선택하면 ${formatBytes(bytes)})';
    }
    _pending = [..._pending, ...added];
    notifyListeners();
    return null;
  }

  void removePending(PendingFile p) {
    _pending = _pending.where((e) => e != p).toList();
    notifyListeners();
  }

  /// 제출(본문 저장)이 끝난 뒤 부른다: 올릴 목록을 서버에 올린다. 성공하면 null.
  Future<String?> uploadPending(int id) async {
    submissionId = id;
    if (_pending.isEmpty) return null;
    _progress = 0;
    notifyListeners();
    try {
      final added = await _repo.upload(
        id,
        [
          for (final p in _pending)
            UploadFile(name: p.name, size: p.size, stream: p.open()),
        ],
        onProgress: (v) {
          _progress = v;
          notifyListeners();
        },
      );
      _files = [..._files, ...added];
      _pending = const [];
      return null;
    } on BusinessException catch (e) {
      return e.message;
    } catch (_) {
      return '파일을 올리지 못했습니다.';
    } finally {
      _progress = null;
      notifyListeners();
    }
  }

  Future<String> download(SubmissionFile file) async {
    try {
      final where = await _repo.download(file);
      return '저장했습니다: $where';
    } on BusinessException catch (e) {
      return e.message;
    } catch (_) {
      return '파일을 받지 못했습니다.';
    }
  }

  Future<String> delete(SubmissionFile file) async {
    try {
      await _repo.delete(file.id);
      _files = _files.where((f) => f.id != file.id).toList();
      notifyListeners();
      return '"${file.name}"을(를) 삭제했습니다.';
    } on BusinessException catch (e) {
      return e.message;
    } catch (_) {
      return '삭제하지 못했습니다.';
    }
  }
}
```

## 4. 자주 막히는 곳 (실제로 겪은 것들)

| 증상 | 원인 | 해결 |
|---|---|---|
| curl 결과 `로그인이 필요합니다` | `$TOKEN`이 비어 있음 (로그인 실패·변수 안 만듦) | `echo $TOKEN`으로 확인 → 로그인 명령 다시 |
| `요청한 주소를 찾을 수 없습니다` (404) | 새 Controller를 만들고 **서버를 안 껐다 켬** | STS에서 서버 재시작 |
| 주소가 `/api/submissions//files` | `$SID` 변수가 비어 있음 | `echo $SID` → `SID=숫자` |
| Git Bash에서 JSON의 `\`가 사라짐 | Git Bash가 역슬래시를 바꿔버림 | JSON은 **작은따옴표** `'{"a":"b"}'`로, 역슬래시 없이 |
| 긴 명령이 STS 터미널에서 깨짐 | 줄이 너무 김 | Git Bash 사용, 한 줄씩 |
| `Parameter 'xxx' not found` | Mapper 메서드에 `@Param` 없음 | `@Param("xxx")` 추가 |
| `@PathVariable` 값이 안 들어옴 | STS 컴파일 옵션 | `@PathVariable("courseId")`처럼 이름 명시 |
| 파일 고르기 후 아무 일도 없음 | file_picker 13: 취소하면 빈 목록 | `if (picked.isEmpty) return null;` |
| 업로드 시 400 | 보내는 key 이름이 `files`가 아님 | Flutter `MultipartFile('files', …)` ↔ 서버 `@RequestPart("files")` |
| 500MB 넘으면 "서버 오류" | `MaxUploadSizeExceededException` 처리 없음 | GlobalExceptionHandler에 413 처리 추가 |
| 커밋 후 `Unlink of file … failed. Should I try again?` | STS가 Git 파일을 잡고 있음 | `n` 입력. 커밋은 이미 됨. `git fsck`로 확인 |
| 대문자 `R` 안 누르고 `r`만 | 생성자·필드 추가는 hot reload로 반영 안 됨 | Flutter 터미널에서 **대문자 R** (hot restart) |
